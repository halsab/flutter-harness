# Visual practice pair

Original illustrative SVGs made for this experiment; not screenshots of
commercial products or validated user research. Both show the same invented
appointment-management utility, with identical data and capabilities.
They are not task-manager answers.

Render both at 390 × 844, inspect the images, then extract the principles.
- appointments-a.svg: deliberately weaker. Decorative hero, repeated headings,
  secondary actions compete with the actual appointments, large top area.
- appointments-b.svg: preferred teaching example. Appointments and time have
  visual priority; spacing groups dates; add and search stay discoverable,
  contextual actions are indicated. The absence of decoration is not itself
  the goal; usefulness and clear hierarchy are. This is a starting example
  not a universal template or owner-approved benchmark.

In another product a dashboard, large chart, persistent search or card may
be exactly right. Do not transplant this layout or brand to every app.
