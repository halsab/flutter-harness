# Brief: tasks (round 1)

Design a high-quality mobile task manager for everyday personal use.
Existing name: «Мои задачи». Language: Russian. iOS, light appearance,
390 × 844 logical pixels, including safe areas. Adaptive profile: native
iOS patterns, system blue accent, neutral surfaces, system typography.
The app has no due dates, priorities, projects, accounts or other features.

Existing capabilities: create a task, mark complete/incomplete, edit title,
duplicate, delete a task, delete all completed tasks (confirm before bulk
deletion), search by title, filter all/active/completed, sort default/title
ascending/title descending, show unfinished count. Preserve all capabilities.
No marketing, renaming, invented data fields or feature scope.

Same populated sample for both concepts:
- Купить продукты (active)
- Записаться к стоматологу (active)
- Прочитать главу книги (active)
- Подготовить документы для поездки (active)
- Ответить на письмо (completed)
- Оплатить интернет (completed)

Initial state: all tasks, default ordering, no query, four unfinished.
Do not invent dates. The primary job is to see, add and complete tasks.
Design the initial populated screen; map creation, search, filter, sort,
rename, duplicate, delete, bulk delete and undo/confirmation as appropriate.
Show where completed tasks and the unfinished count can be found.
The two concepts must use the same sample and target screen.

Follow RUN.md in this directory.
